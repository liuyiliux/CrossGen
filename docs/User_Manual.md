## 1. 简介

逸流是一款基于 AI 的一站式内容创作工具，支持**一键生成**适用于小红书、抖音、公众号等平台的图文内容。它集成了 GPT、Claude 等大语言模型与 Stable Diffusion 图像生成能力，帮助创作者高效产出专业内容。

## 2. 快速入门

请确保您已按照 `README.md` 中的安装指南成功启动了项目。

- **前端地址**: `http://localhost:3001`
- **后端地址**: `http://localhost:8000`

打开前端地址，您将看到系统首页。

## 3. 核心功能

### 3.1 灵感获取与导入

这是逸流的特色功能，允许您从小红书等平台获取灵感，并直接转化为创作素材。

**操作步骤：**

1.  点击导航栏或首页的 **"灵感获取"** 卡片。
2.  **搜索模式**：在搜索框输入关键词（如"冬日穿搭"），点击搜索。系统将展示相关热门笔记。
3.  **解析模式**：切换到"链接解析"标签，粘贴小红书笔记链接，点击解析。
4.  **导入创作**：
    - 点击任意卡片上的 **"导入"** 按钮（或详情页的导入按钮）。
    - **关键功能 - 参考图导入**：在弹出的对话框中，勾选 **"同时导入图片作为参考图"**。
    - 选择导入类型（仅标题、仅描述或两者）。
    - 点击确认，系统将自动下载选中笔记的图片（最多5张），并跳转回首页。

> **提示**：勾选参考图导入后，系统会自动将原笔记图片设置为 AI 绘图的参考图，极大提升生成图片的风格还原度。

### 3.2 图文创作

首页是创作的核心区域。

**操作流程：**

1.  **输入主题**：直接输入主题，或通过"灵感获取"导入。
2.  **上传/管理图片**：
    - 如果使用了灵感导入，此处会显示已导入的参考图。
    - 您也可以点击图片图标手动上传本地图片作为参考。
3.  **选择平台与服务商**：
    - **平台**：选择发布目标（如"小红书"、"反推"等），系统会应用相应的文案风格模板。
    - **文本服务商**：选择用于生成文案的 AI 模型（如 SiliconFlow, OpenAI）。
4.  **生成大纲**：点击 **"生成大纲"**。AI 将生成包含标题、文案和分镜提示词的结构化大纲。
5.  **编辑优化**：
    - 在大纲预览页，您可以修改标题、文案内容。
    - 调整每一页的图片提示词。
6.  **生成图片**：满意大纲后，点击 **"生成图片"**。系统将调用绘图模型生成最终图片。
7.  **保存与导出**：生成完成后，结果自动保存至"历史记录"，支持打包下载。

### 3.3 批量生成

适用于需要一次性产出大量内容的场景。

1.  进入 **"批量生成"** 页面。
2.  在文本框中输入多个主题，每行一个。
3.  配置通用的平台和服务商设置。
4.  点击开始，系统将进入队列处理模式，依次生成所有内容。

## 4. 配置管理

点击导航栏的 **"配置管理"** 进入设置页。

- **系统配置**：查看数据库连接、日志级别等（通常由运维人员在配置文件中管理）。
- **平台模板**：自定义不同平台的 Prompt 模板。例如，您可以修改"小红书"模板，要求 AI "多使用 Emoji" 或 "语气更活泼"。
- **AI 服务商**：配置 OpenAI、SiliconFlow 等 API Key。

## 5. 常见问题

**Q: 导入灵感时图片没有显示？**
A: 请确保在导入对话框中勾选了"同时导入图片作为参考图"。如果原笔记图片受版权保护或网络限制，可能会导致下载失败，此时系统会仅导入文本。

**Q: 生成图片速度很慢？**
A: 图片生成依赖于 GPU 资源或云端 API 响应速度。请检查 `image_providers.yaml` 中的配置，或尝试切换图像服务商。

**Q: 如何清除历史记录？**
A: 进入"历史记录"页面，选择对应的记录点击删除，或直接在服务器端清理 `backend/history` 文件夹（注意备份）。
